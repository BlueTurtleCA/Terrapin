### PLATFORM: Windows
You are running on Windows.
- Shell command lines (pipes, redirects, multiple statements) are executed by PowerShell, so use PowerShell syntax in them: `;` separates statements, `$env:VAR` reads environment variables, and cmdlets such as Get-ChildItem and Select-String replace ls and grep.
- Common commands available: git, swift, and the standard PowerShell cmdlets.
- Paths use drive letters and backslashes (e.g. C:\Users\<user>\...).
